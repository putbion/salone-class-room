Orange Money API Integration

Use this area when you are ready to connect an official Orange Money merchant/payment API. Sensitive API secrets are never stored in this dashboard. Keep them only in Netlify Environment Variables.

Required secret environment variables can later be added in Netlify, for example: ORANGE_MONEY_CLIENT_ID, ORANGE_MONEY_CLIENT_SECRET, ORANGE_MONEY_MERCHANT_KEY. The exact names can be adjusted to match Orange Sierra Leone's API documentation when you receive merchant credentials.
